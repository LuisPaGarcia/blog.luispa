I know, is really late to say this. The wave is here.

1. The realization: Is time to pivot. 

I've been a software engineer for like 11 years. Working with people across the globe in startups, tiny companies and big tech companies. That cannot be erased, what is done is done. But I think that is not the path anymore. 

For some reason I have a lot of doubts about myself recently.

2. The evidence. Even with evidence the future is kinda scary.

Even after knowing there's evidence of the things I can achieve, I still have a lot of issues about how I can add value after the software is done by AI.

I know can solve complex problems. I have evidence.
I know can lead teams. I have evidence.
I know can communicate properly. I have evidence.

But now, I think this is not useful anymore in the same way it was before. For sure I know this is not the way.

You can ignore the reality if you really want, but the reality will not ignore you.

Software engineering as we know it is done forever.

3. The next steps.

If in the past I could have the capabilities to adapt to the market, I know for sure I can addapt to a AI role related with confidence.

I remember when I was a backend engineer trying to center a div, thinking "Ah man, I suck at this. I will be a backend engineer for life" and 2 years later working as a lead frontend engineer. I know for sure I can adapt. 

For now I want to have a path (even if is not a clear path) to move ahead about my career, and then make cools stuff. 

So the plan is:

1. Find a good resources on how to create a path.
2. Create the first draft of the path.
3. Educate myself with proper sources.
4. Revisit the path.
5. Create projects and share them. 
6. Find some opportunities with networking.
x. Keep looping until I have some new proffesional adventures.

For now, writing this is enough. Now the hard part!

Happy Hacking!
